# Local LLMs

Course repository for **Local LLMs** by **AI University**.

## Цель

Изучить запуск, настройку, оптимизацию и практическое применение
локальных больших языковых моделей (LLM).

## Course workflow

Каждый урок проходит по единой схеме:

1. Теория
2. Основные понятия
3. Инструменты
4. Практический эксперимент
5. Код
6. Домашнее задание
7. Проверка результата
8. Выводы
9. Идеи для применения в собственных проектах
