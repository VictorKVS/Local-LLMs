# Projects

Крупные практические проекты курса.

Проект попадает сюда, когда выходит за рамки одного notebook или одного ДЗ и имеет собственную архитектуру, API, UI или lifecycle.

Планируемые направления:

- AI Content Maker Lite;
- RAG / Knowledge Lab;
- Local Model Router;
- Evaluation Lab;
- FATHER Model Gateway.
