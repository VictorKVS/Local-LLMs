# Local LLMs Showcase v0.2

Многостраничная версия сайта, специально подготовленная для нормальной навигации и скриншотов.

## Страницы

- `index.html` — главная / общий вид;
- `lab.html` — runtime и GPU telemetry;
- `models.html` — Model Zoo;
- `architecture.html` — архитектура;
- `dz1.html` — ДЗ №1 и эксперименты;
- `roadmap.html` — развитие проекта.

## Локальный запуск

```powershell
cd "G:\1\Local LLMs"
python -m http.server 8080 --directory ".\site"
```

Открыть:

```text
http://127.0.0.1:8080/
```

## Рекомендуемый размер окна для скриншотов

Оптимально:
- 1440 × 900
- масштаб браузера 100%

Каждая страница спроектирована так, чтобы основной контент помещался на один экран или требовал минимальной прокрутки.

## Какие скриншоты сделать

1. `01_home.png` — главная;
2. `02_lab.png` — GPU/runtime;
3. `03_model_zoo.png` — Model Zoo;
4. `04_architecture.png` — архитектура;
5. `05_dz1.png` — параметры эксперимента;
6. `06_roadmap.png` — развитие проекта.

## Установка поверх v0.1

Скопировать содержимое папки `site` в:

```text
G:\1\Local LLMs\site
```

с заменой существующих файлов.
