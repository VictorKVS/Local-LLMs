# Benchmarks

Сравнительные измерения локальных моделей.

## Базовые метрики

- prompt tokens / sec;
- generation tokens / sec;
- latency;
- VRAM;
- RAM;
- temperature;
- instruction following;
- coherence;
- logic correctness;
- completion / truncation;
- manual notes.

## Принцип

Скорость без качества не является итоговой метрикой. Для Model Router важна комбинация:

```text
quality + latency + VRAM + stability + task fit
```
