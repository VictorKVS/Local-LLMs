# Screenshot Guide

Сайт проектируется так, чтобы экран можно было вставить в учебный отчёт без ручной верстки.

## Рекомендуемый режим

```text
Viewport: 1440 × 900
Browser zoom: 100%
```

Для чистого кадра добавить к URL:

```text
?shot=1
```

Примеры:

```text
/dz1.html?shot=1
/models.html?shot=1
/architecture.html?shot=1
```

## Требования

- не снимать с масштабом 67–80%;
- не включать лишнюю панель браузера, если она не нужна;
- не обрезать заголовок и статус;
- один скриншот = одна главная мысль;
- не пытаться уместить весь сайт в один длинный кадр.
