# Course Repository Structure

## Назначение

`Local-LLMs` — единый репозиторий всего курса. Он одновременно выполняет четыре функции:

1. учебный журнал;
2. reproducible lab;
3. портфолио;
4. источник компонентов для FATHER.

## Каноническая структура

```text
Local-LLMs/
├── README.md
├── lessons/                    # конспекты и материалы уроков
├── homeworks/                  # задания и шаблоны
├── DZ_1_Local_LLMs_First_Model/
├── experiments/                # независимые эксперименты
├── benchmarks/                 # сравнительные тесты
├── notebooks/                  # Jupyter
├── model_inventory/            # машиночитаемый реестр
├── models/                     # только metadata / manifests, не веса
├── projects/                   # более крупные практические работы
├── scripts/                    # автоматизация
├── docs/                       # архитектура, стандарты, отчётность
└── site/                       # публичная витрина / GitHub Pages
```

## Стандарт домашнего задания

Каждое ДЗ стремится к одинаковой структуре:

```text
DZ_N_Name/
├── README.md
├── TASK.md
├── src/
├── notebooks/
├── data/
│   ├── raw/
│   └── processed/
├── reports/
├── screenshots/
└── tests/
```

## README каждого ДЗ

README должен отвечать на вопросы:

- какая цель;
- что именно проверяется;
- какое окружение использовано;
- какие параметры менялись;
- какие результаты получены;
- как воспроизвести;
- что получилось хорошо / плохо;
- какие выводы;
- что переиспользуется в FATHER.

## Правило артефактов

В GitHub хранятся:

- код;
- конфигурации;
- небольшие CSV/JSON;
- отчёты;
- графики;
- скриншоты;
- manifests.

Не хранятся:

- веса моделей;
- Hugging Face cache;
- секреты;
- виртуальные окружения;
- временные runtime-файлы.
